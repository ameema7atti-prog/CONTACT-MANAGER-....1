# Contact Manager Application 📇

A full-stack contact management web application built for **Project 2** of **Task 3** in the **Syntecxhub Web Development Internship**[cite: 38, 42]. This application enables users to manage contact details efficiently with robust form validation and error handling[cite: 42].

## 🚀 Features
* **CRUD Operations:** Full create, read, update, and delete functionality for managing contacts[cite: 42].
* **Validation & Error Handling:** Implements basic validation checks and error handling mechanisms to ensure correct user input[cite: 42].
* **Full-Stack Architecture:** Built using React for a dynamic user interface and Node.js with Express for the backend[cite: 42].
* **Database Storage:** Persistently stores contact information in MongoDB[cite: 42].

## 🛠️ Tech Stack
* **Frontend:** React.js, HTML5, CSS3[cite: 42]
* **Backend:** Node.js, Express.js[cite: 42]
* **Database:** MongoDB[cite: 42]
